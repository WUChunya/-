# 插图生成器 · Illustration Generator

Free tools for architecture students: one Rhino model in, a full set of diagrams out.
给建筑学生的免费出图工具：一个 Rhino 模型进去，一整套分析图出来。

By Chunya Wu · Free for study and personal projects; please do not re-upload or sell. 仅供学习和个人项目使用，请勿二次上传或售卖。

| Tool · 工具 | What it does · 做什么 | Folder |
|---|---|---|
| **Program Diagram** (Rhino 8 plugin, Windows) | Massing model → layered Illustrator diagrams: site plan, floor plans, sections, elevations, stacked / exploded axons, program charts. 体块模型 → 分层 AI 分析图：总平、平面、剖面、立面、叠合 / 爆炸轴测、面积图 | [`ProgramDiagram/`](ProgramDiagram/) |

Each tool lives in its own folder with its own README, download and example model.
每个工具一个文件夹，各自有说明、安装包和示例模型。
